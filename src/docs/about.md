# About Rishav Singh

I am an AI & GenAI engineer with a data analysis specialty, currently pursuing my B.Tech in Artificial Intelligence and Data Science at MIT World Peace University, Pune (2023–2027, CGPA: 7.60/10).

Most AI demos look great inside a notebook but fall apart when deployed: APIs run up bills, LLMs hallucinate numbers, or the whole app halts if the internet drops. I spend my time building systems that bypass those failure modes:

- **Jurista:** A legal research copilot built with LangChain and Google Gemini, grounded in Indian statutory texts (BNS, IPC, CrPC, Constitution) with a dynamic search router to cross-check live judicial records only when needed.
- **VeeraServe AI:** An agentic restaurant waiter built on LangGraph with 12 validated tools. It runs locally via LM Studio, grounds every menu item using Chroma RAG, and achieved 0% hallucinated prices in measured evaluation runs.
- **Local AI Dashcam:** A 5-phase offline pipeline using YOLO11, SORT tracking, and optical flow to detect road incidents locally. Flagging keyframes first cut expensive VLM inference calls by about 80%.
- **Justify-AI / Research:** A multilingual hate speech detection framework spanning five Indian languages (English, Hindi, Marathi, Bhojpuri, Marwari) using classical NLP for transparent risk scoring. Accepted to an IEEE conference (lead author; revisions in progress).
